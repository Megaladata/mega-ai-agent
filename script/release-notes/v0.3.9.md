# Mega AI Agent v0.3.9 — what's new

Changes since v0.3.8. Starting with this version the application is named **Mega AI Agent**. It adds eight node types and modes that the agent builds with native Megaladata nodes, and new capabilities of nodes that were already available.

## New nodes and modes

- **Excel export.** The agent writes a scenario result to an `.xlsx` file with the standard Megaladata Excel export node. Types, column order, headers, and NULL are preserved.
- **Trees: JSON to tree and tree to table.** The agent parses JSON into Megaladata tree data and expands a tree back into a table. Both modes are supported: repeating parent values on descendant rows, and leaving them only on the first row. Long integers are passed exactly.
- **Autocorrelation.** The autocorrelation function of a series is calculated by the native Autocorrelation node, with a chosen lag count.
- **Smoothing.** Series smoothing with the Hodrick–Prescott filter. If Megaladata cannot compute the smoothing, for example when every value is empty, the agent reports the Megaladata error text and does not invent a result.
- **Binning.** Numeric fields are split into intervals by count, width, or frequency, including applying a trained binning to new data.
- **Sampling and data partition: random mode.** A random sample and a random split into training and test sets, with a reproducible seed.
- **Date and time: ISO weeks.** ISO year, ISO week number, the first day of the ISO week, and the day of week.
- **Logistic regression: stepwise factor selection.** Forward, Backward, and Stepwise use the standard Megaladata criterion and thresholds.

## New capabilities of existing nodes

- **Excel import:** choose a workbook sheet by name, and up to 12 columns. Previously this was the first sheet and up to 8 columns.
- **Missing values:** replace empty numeric values with zero using the native Megaladata method, including a completely empty field.
- **Grouping:** unique count for integer and string fields. Empty values are not counted.
- **Date and time:** extract minutes and seconds.
- **Text export:** Windows-1251 encoding for exchange with older systems, only when the user asks for it. The default remains UTF-8.
- **Replacement:** choose the result type, and match numeric values at a given precision: the nearest key within the tolerance.
- **Cross table:** continuous row keys, including real numbers. An empty key is its own group.
- **Union:** automatic field matching by name or label and by type. The agent does not guess ambiguous labels; it reports them.
- **Clustering:** standardize features before k-means when they use different units. Cluster centers are returned in the original units.

## Connection

- **The knowledge-service key no longer has to be typed.** The key is built into the application. A connection asks only for the Megaladata address, username, and password. A key saved by an older build is not sent, and the connection does not need to be reconfigured.
- **The action catalog ships with the application.** The agent no longer downloads the action catalog from the knowledge service when a chat starts.

## Fixes and reliability

- Fixes from v0.3.8 are included.
- **REST response with nested objects, as a table.** The agent builds the table from a REST JSON response with standard table nodes: Calculator, Collapse columns, and Cross table. Tree nodes are used only when the user asks for a tree.
- **Megaladata error while opening a package.** If Megaladata could not render a saved package, the agent closes its own tab and does not leave it open.
- **New nodes after Import and other sources.** The agent executes the source before building a node that reads it, and does not receive the refusal that an active source output is required.
- **Executing an Import with an empty table** no longer stops before launch.
- **Reconfiguring Grouping.** The agent waits until Megaladata removes its own mask, instead of refusing with "Port opening blocked".
- **Startup diagnostics.** A normal shutdown of the help service after a successful preparation is no longer recorded as a startup failure.
- **Agent skill.** The agent copies a help resource path exactly. A full Grouping reconfiguration sends every grouping field and the input at once, without extra refusals.
- **Agent skill size.** Detailed node settings live in a separate reference that the agent reads when it needs them, so the skill stays within the tool output limit.

## Known limitations

- **ISO weeks.** "Last day of the ISO week" is not supported. Megaladata calculates it incorrectly at a year boundary, for late December dates that belong to week 1 of the next year. The agent reports this limitation.
- **Sampling and partition.** Stratified mode and biased mode are not supported yet. The agent says so.
- **Logistic regression.** Choosing the selection criterion, such as AIC or BIC, and custom inclusion or exclusion thresholds are not supported yet. Standard Megaladata values are used.
- **Windows-1251 text export.** Characters that are not in that encoding, for example CJK characters and emoji, are replaced by Megaladata with a substitute character. The agent warns about this.
- **Clustering.** Among normalization methods, only standardization is supported. Distance then uses normalized units.
- **Cross table.** Continuous fields are allowed only as row keys. Columns remain discrete. This is a Megaladata limitation.
- **macOS.** The Apple Silicon build (arm64, macOS 14+) is ad-hoc signed, without a Developer ID or notarization. macOS shows a security warning on the first launch.
