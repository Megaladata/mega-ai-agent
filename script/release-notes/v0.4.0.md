# Mega AI Agent v0.4.0 — what's new

Changes since v0.3.11. This brings the Loginom v0.4.0 client work into Mega AI Agent: workflow variables, native Megaladata Data (LGD), control nodes, Python, many new node modes, and a preview of node dashboards.

The default connection stays `https://agent.megaladata.com/app/`. Help and the action catalog are local. The app does not call `https://mcp.megaladata.ai`.

## Help and connection

- The Megaladata user guide ships with the app. Search, read, and synonyms run offline from the bundled pages. A connection check loads that local help first, then opens the stand in the browser.
- Check does not save a connection. The first-run screen stays open until a connection is saved and activated.

## Node dashboards (preview)

- Megaladata Studio can open a node dashboard in Desktop or the CLI. The agent receives a one-time snapshot, builds a local draft, and shows a preview. Further edits happen in chat.
- Publish and delete each ask for a separate confirmation. If the published version changed, the agent explains the conflict and asks again. Deleting from the CLI requires typing the one-time `Delete <code>` phrase.
- Publishing needs the Dashboard service for Megaladata Enterprise 7.4.2. That service is not bundled in this app.

## Desktop and CLI

- Help → Collect diagnostics builds an archive of the chat, execution journals, and application logs, with an optional crash dump. Passwords, keys, the login, and internal server addresses are removed. The archive can still contain chat text and pieces of data. The CLI command is `diagnostics export`.
- ripgrep is bundled with Desktop and the CLI, so file search does not download it on first use.
- The system proxy is chosen per connection. An unreachable system proxy is skipped and the CLI continues directly.
- CLI builds for Windows and Linux x64 run on older CPUs without AVX2. `mega-ai-agent status` shows the saved connection without starting a session.
- Resource integrity is checked at install and CLI setup. Chromium is prepared before the first connection check. Uninstall removes the app URI registration.

## Workflow variables

- Variable Calculator writes integer, real, string, boolean, and datetime variables, including intermediate expressions.
- Table to Variables and Variables to Table convert both ways, as columns or rows, including typed NULL and 14 aggregate functions.
- Variable union, variable replacement, and user workflow variables are available. Node settings can take paths, filters, grouping, sorting, REST headers, and export file names from variables.

## Megaladata Data (LGD)

- Import and export 64-bit LGD, including compression, checksums, an empty schema, Variant cells, and a path from a variable. Overwrite is explicit. 32-bit files and Deductor DDF are not supported, and an existing LGD file cannot be appended.

## Nodes

- Supernode, Condition, and Loop. Python, when the server administrator has enabled it, with a source check that allows pandas, numpy, and the standard library and refuses files, network, and processes. JavaScript can be a source with no inputs, and Calculator can use JavaScript for the whole node.
- Text, Excel, and SQLite import. Text export gains fixed width and Unicode encodings. Excel export gains number styles and workbook replacement. REST gains POST, PUT, PATCH, DELETE, custom headers, XML and text responses, and a file-based simulated response.
- Logistic and linear regression, coarse classes, factor analysis, association rules, clustering, Spearman and Kendall correlation, autocorrelation, binning, wavelet smoothing, outlier editing, and data quality.
- Grouping, trees, data enrichment, ungroup, column union by position, sampling and partition, missing-value fill, replacement, sorting, join, union, cross-table, column collapse, field parameters, and date/time features.

## Known limits

- Recommended resolution is 1280×800 or higher. On a smaller screen, a node placed far outside the visible workflow may be refused. Automatic placement still works.
- Coarse classes cannot apply an external partition in Megaladata 7.4.2.
- JavaScript Fetch is not executed.
- The Python check is not a sandbox. Restrict the server Python environment with OS permissions.
- This build does not include the Loginom release's live-scenario sign-off. Linux and Windows builds are unsigned. macOS, when built, is ad-hoc signed without Developer ID or notarization.
