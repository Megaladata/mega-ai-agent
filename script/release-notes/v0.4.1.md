# Mega AI Agent 0.4.1

Fixes carried from the 0.4.1 platform client, with the local Help bundle, the bundled action catalog, and the disabled update feed kept as they are.

- Sign-in distinguishes a rejected login from an unavailable login page.
- Text and Excel import recover a replaced source before capturing the previous output layout, and a changed delimiter rebuilds columns once.
- REST additional parameters are read from the active page before simulation settings are applied.
- Node preparation keeps readiness when the full node catalog does not fit in one reply. Describe accepts JSON-encoded list arguments.
- JSON-to-tree reads a single document, including a root array of objects in one string field.
- Export input links can be replaced only when the user asks, and a failed opening of an export port is released.
- Binary spreadsheet attachments stay behind a local receipt instead of being sent to the model as file bytes.
- Package quality review is a separate `package-linter` skill. It reads a local `.mgp` and writes an English report next to the source. It does not run the scenario.
