# Mega AI Agent v0.3.11 — what's new

Changes since v0.3.10. These are the product fixes from Loginom v0.3.10.

## First connection

- The application stays on the connection screen until the first Megaladata connection is saved and activated. The entered address, username, and password remain after a failed attempt, so they can be corrected and saved again.
- If the saved connection profile cannot be read, it is loaded again instead of leaving setup stuck.

## Scenario graph

- An export node keeps its place when the component palette is redrawn.
- Before a link is created, the source node is brought into view, including its ports.
- Preview reading no longer stops only because a wizard keeps more than 16 cached forms.
- After browser recovery, an unfinished node is released only when its graph is actually quiet. A completed browser step is not treated as a discarded draft.

## Knowledge service

- A knowledge-service startup failure records the connection stage and error class. The knowledge process directory is kept after a connection check so that close evidence remains available.
