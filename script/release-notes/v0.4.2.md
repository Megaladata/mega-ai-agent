# Mega AI Agent 0.4.2

Fixes carried from the 0.4.2 platform client. The local Help bundle, the bundled action catalog, and the disabled update feed stay as they are.

- An authorized XLSX up to 16 MiB whose only change is the timestamp can be confirmed again when the path, file id, size, and exact-scan SHA-256 still match.
- Python caches are not copied into the bundled skills.
- Variable inputs are checked on the node that owns them, including an MGD export bound by the label shown in the wizard.
- A JavaScript selection is released when a gesture is refused before it is applied. A refusal with no effect does not keep the node busy.
- A text-import variable binding can be recovered, and a finished source preview releases the import.
- Scan profiles keep the exact file identity.
- Wait for a node with `megaladata_dock_node_wait`. Do not use shell `sleep`, and do not unpack an attached `.mgp`.
