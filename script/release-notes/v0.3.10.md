# Mega AI Agent v0.3.10 — what's new

Changes since v0.3.9.

## Package save

- A package is saved in the signed-in Megaladata account folder. The agent no longer requires the fixed path `/user/data/packages`, which belongs to the default account `user`.

## File import

- After a file upload, a Text File or Excel import is created on the first attempt. The delivery operation id is accepted as the upload receipt, so the agent does not stop with "Verified upload operation is missing or ambiguous" and then repeat the same node.

## Scenario guidance

- The built-in scenario skill now includes the procedures that were shorter than in Loginom v0.3.9: large files, server storage, a sample followed by the full calculation, calculator formula errors, and saving the agent's own package copy. Limits for binning, clustering, and the other v0.3.9 nodes are stated in the skill.
