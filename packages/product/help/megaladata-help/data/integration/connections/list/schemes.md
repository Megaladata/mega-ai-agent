# ![ ](../../../images/icons/data-sources/file-xml_default.svg)&nbsp;XSD Schema Set Connection

Use it to connect to [XSD files](https://en.wikipedia.org/wiki/XML_Schema), specifying the connection parameters for a list (set) of schema files.

## Connection parameters

To configure the connection, you need to list some paths to XML schema files. The wizard toolbar contains the following commands:

* ![ ](../../../images/icons/toolbar-controls/plus_default.svg)&nbsp;**Add**: Adds a new XSD schema file to the list, selected by the user in the file selection dialog.
* ![ ](../../../images/icons/toolbar-controls/moveup_default.svg)&nbsp;**Up** or ![ ](../../../images/icons/toolbar-controls/movedown_default.svg)&nbsp;**Down**: Changes the position of the selected item in the list.
* ![ ](../../../images/icons/toolbar-controls/edit_default.svg)&nbsp;**Change**: Opens the file selection dialog to edit the path to the XSD file.

List-changing commands:

* ![ ](../../../images/icons/toolbar-controls/delete-all_default.svg)&nbsp;**Delete all**: Located in the top right of the list; deletes all listed files. 
* ![ ](../../../images/icons/toolbar-controls/delete_default.svg)&nbsp;**Delete**: Deletes the selected item from the list.
