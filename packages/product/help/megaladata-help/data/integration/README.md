# Integration

Integration enables data exchange between the Megaladata platform and third-party systems. Megaladata can connect to [web services](./web-services/README.md), databases, and file-based sources, such as spreadsheets and text files.

> **Important Note**: To integrate with external data sources such as databases or web services, you must first configure a [connection](./connections/README.md).

The further description of integration process consists of the following sections:

* **Connections:** Describes how to configure access parameters for external systems and save them for reuse.
* **Data import:** Describes the nodes used to get data from external sources for processing in Megaladata.
* **Data export:** Describes the nodes used to send processed data to external systems for storage, use, or publication.
* **Web services:**  Describes how to use Megaladata to interact with web services.
