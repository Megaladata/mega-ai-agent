# Megaladata — User Guide

[**Megaladata**](https://megaladata.com/) is a low-code analytical platform that allows you to perform all stages of business analysis within a single environment—from data consolidation and model training through to visualization and integration into your business processes.

![The Megaladata platform elements](./mgd-components.svg)

Megaladata Desktop and Megaladata Studio offer similar functionality, except in integration and teamwork capabilities, which Desktop doesn't provide.

Megaladata's analytical platform is available in six editions:

* Community
* Personal
* Team
* Standard
* Enterprise
* Cloud

To choose the suitable edition, consider use cases and integration into the corporate IT environment, not the availability of processing algorithms and visualization methods, which are the same in all versions.
For more details about the available Megaladata editions, please refer to [Available Editions](https://help.megaladata.com/userguide/compare-editions.html).
