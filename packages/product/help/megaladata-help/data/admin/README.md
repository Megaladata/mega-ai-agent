# ![Administration](../images/icons/app/system-toolbar/controls/admin_default_mgd.svg)&nbsp;Administration

This section of the application interface is designed to control [users](./users.md), [shared folders](./shared-folder.md) and [server parameters](./parameters.md), as well as to monitor and control open sessions and packages via the **Session Manager**. As opposed to the server editions (Team, Standard, and Enterprise), the Administration pane of the desktop editions (Community and Personal) includes only one page: **Parameters**.

In the server editions, only users with the **Admin** role have access to the section.

> **Important:** The platform has a preconfigured admin user with the **Admin** role and an `admin` password. After the system setup, password change is required.
