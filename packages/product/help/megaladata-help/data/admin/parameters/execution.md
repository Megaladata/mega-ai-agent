# Component Parameters: Program Execution

Use the following parameter to control running [Program Execution](../../processors/integration/exec-program.md) nodes in your workflow:

|Parameter|Default value|Description|
|:-|:-|:-|
|Execution forbidden|`true`|Running **Program Execution** nodes is disabled. Set the value to `false` to enable it.|

To apply your changes, click ![](../../images/icons/toolbar-controls/save_default.svg)&nbsp;**Save**.

> **Note:** In Megaladata desktop editions, running the **Program Execution** nodes is *allowed* by default. You can always restrict it if necessary.
