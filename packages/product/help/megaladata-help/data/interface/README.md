# User Interface

Megaladata's main window is organized into four main panes:

![Application window](./ui_layout.png)

1. [Main menu](./main-menu.md): Contains commands for managing files, adjusting settings, and accessing other platform features. The main menu may vary depending on the platform's edition (Server/Desktop), user rights, and visualization tools employed.
2. [Address bar](./addres-bar.md): Displays the path to the currently open item (e.g., package, workflow).
3. [Workspace](./workspace.md): This central area provides tools for performing the main actions such as building workflows, configuring connections or reports, administrating the platform, etc. The elements and commands available in this area, and its overall design vary depending on what Megaladata page/window is currently open.

4. [Processes pane](./processes-panel.md): Shows detailed information about processes that are currently running or have finished within the nodes of your workflow.
