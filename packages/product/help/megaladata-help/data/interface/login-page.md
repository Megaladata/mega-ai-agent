# Login Page

In Megaladata's server editions, accessing Megaladata Studio in your browser starts with the **login page**:

![The login page](login-interface.png)

The page contains the following elements:

- **Username**: Username.
- **Password**: User password.
- **Sign In**: Authorization button.
- **Version: X.X.X**: Program version.
- [Introduction to Megaladata](https://youtu.be/rcQ2VczrHXE?si=hBqVHSizgd6dM666): A link to Megaladata's tutorials in YouTube.
- [Quick Start](https://megaladata.com/platform/quick-start): A link to Megaladata's onboarding videos.
- [User Guide](https://help.megaladata.com/userguide/): A link to this User Guide.
- [Q&A](https://www.reddit.com/r/Megaladata/): The official Megaladata subreddit.
