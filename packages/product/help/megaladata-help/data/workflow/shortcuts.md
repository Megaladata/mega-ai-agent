# Keyboard Shortcuts

When designing workflows, you can use the following shortcuts:

* <kbd>CTRL</kbd> + <kbd>X</kbd>: to cut the selected item(s)
* <kbd>CTRL</kbd> + <kbd>C</kbd>: to copy the selected item(s)
* <kbd>CTRL</kbd> + <kbd>V</kbd>: to paste the content from the clipboard (where the mouse cursor is located)
* <kbd>CTRL</kbd> + <kbd>A</kbd>: to select all workflow nodes
* <kbd>Delete</kbd>: to delete selected
* <kbd>F2</kbd>: to rename a node
* <kbd>F3</kbd>: to open the quick view of output data
* <kbd>F9</kbd>: to run the selected node
* <kbd>Shift</kbd> + <kbd>Enter</kbd>: to enter a node config wizard
* <kbd>Enter</kbd>: to enter a supernode
* <kbd>CTRL</kbd> + <kbd>Enter</kbd>: to enter a supernode in a new window
* <kbd>Backspace</kbd>: to exit a supernode
* <kbd>CTRL</kbd> + <kbd>Backspace</kbd>: to exit a supernode and move to a new window
