# Configuring "Table" and "Variables" Ports

In the port configuration wizard, you can define and fix the data structure that the port outputs. If necessary, you can override the composition, order, and parameters of the input data fields/variables and/or align them with the data structure that the node expects. Do this by mapping the input and output fields/variables of the port. 

The **Inputs** list shows the structure of the data that the port accepts. The **Outputs** list shows the required result structure.

The wizard provides two configuration interfaces:
- Use [**Links**](interface-links.md) to create and rearrange links between the inputs and outputs in a visual editor.
- Use [**Table**](interface-table.md) to map fields/variables in tabular form.

For details, proceed to subsections.
