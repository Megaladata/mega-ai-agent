# Variables

A [variable](../../workflow/variables/README.md) is a named object that can contain only one value of a specific type. Megaladata operates several types of [variables](../../workflow/variables/workflow-variables.md).

Use variable values in calculations—for example, in the [Calculator](../../processors/transformation/calc/README.md), [Condition](../control/condition.md), and other nodes. Also, you can create [control variables](../../workflow/variables/control-variables.md) to set configuration parameters for nodes.

Megaladata provides dedicated components for working with variables. You can find them in the **Variables** group on the **Components** pane. For details, proceed to the subsections.
