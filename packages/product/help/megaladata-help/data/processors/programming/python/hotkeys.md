# ![](./../../../images/icons/components/python_default.svg)&nbsp;Hotkeys

The following keyboard shortcuts are supported in the code editor:

- <kbd>Ctrl</kbd> + <kbd>Space</kbd>: Code autocompletion
- <kbd>Ctrl</kbd> + <kbd>/</kbd>: Comment/uncomment code
- <kbd>Shift</kbd> + <kbd>Tab</kbd>: Dedent selected code
- <kbd>Tab</kbd>: Insert four spaces. If more than one line is selected, it indents the selected lines of code.
